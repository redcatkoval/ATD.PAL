# ATD.PAL Frontend

Современный адаптивный фронтенд для проекта ATD.PAL, созданный на основе дизайн-системы из Figma.

## 🚀 Возможности

- **Адаптивный дизайн**: Полностью адаптивная верстка для десктопа, планшетов и мобильных устройств
- **Темная/светлая тема**: Переключатель тем с сохранением предпочтений пользователя
- **Современный UI**: Пиксель-перфект верстка на основе дизайн-системы Figma
- **Компонентная архитектура**: Модульная структура React компонентов
- **Дизайн-токены**: CSS переменные для единообразного дизайна

## 🎨 Дизайн-система

### Цвета
- **Primary**: `#F85A00` (оранжевый)
- **Background**: `#FFFFFF` / `#0F0F0F` (светлая/темная тема)
- **Surface**: `#F8F9FA` / `#1A1A1A`
- **Text Primary**: `#1A1A1A` / `#FFFFFF`

### Типографика
- **Заголовки**: Montserrat Bold
- **Основной текст**: Inter Regular/Semi Bold
- **Адаптивные размеры**: Автоматическое масштабирование для мобильных устройств

### Компоненты
- Кнопки с состояниями (primary, secondary, disabled)
- Поля ввода с фокусными состояниями
- Карточки сообщений
- Модальные окна и боковые панели

## 📱 Мобильная адаптивность

- **Breakpoints**: 768px (планшеты), 480px (мобильные)
- **Touch-friendly**: Минимальный размер кнопок 44px
- **Мобильная навигация**: Выдвижное боковое меню
- **Оптимизация iOS**: Предотвращение зума на полях ввода

## 🛠 Технологии

- **React 18**: Современные хуки и функциональные компоненты
- **Vite**: Быстрая сборка и HMR
- **Tailwind CSS**: Utility-first CSS фреймворк
- **CSS Variables**: Дизайн-токены для тем
- **Google Fonts**: Inter и Montserrat

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 🎯 Основные компоненты

### AuthLayout
Общий макет для страниц авторизации с:
- Логотипом ATD.PAL
- Переключателем тем
- Адаптивным дизайном

### AIChat
Основной компонент чата с:
- Боковой панелью контекстов
- Областью сообщений
- Формой ввода с голосовыми возможностями
- Мобильной навигацией

### ThemeToggle
Переключатель тем с:
- Сохранением в localStorage
- Поддержкой системных предпочтений
- Плавными переходами

## 🔧 Кастомизация

### Изменение цветов
Отредактируйте CSS переменные в `src/index.css`:

```css
:root {
  --color-primary: #F85A00;
  --color-primary-hover: #E64A00;
  /* ... другие переменные */
}
```

### Добавление новых компонентов
1. Создайте компонент в соответствующей папке
2. Используйте существующие CSS классы из дизайн-системы
3. Следуйте принципам адаптивности

## 📊 Производительность

- **CSS оптимизация**: Purged CSS в продакшене

- **Web Vitals**: Оптимизировано для Core Web Vitals
