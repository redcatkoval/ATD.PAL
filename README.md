# ATD.PAL
Friendly AI assistant for AUTODOC employees

## Функциональность

### Чат-бот
- Обработка сообщений пользователя с использованием модели Claude 3.5 Sonnet
- Система управления состоянием диалога для многошаговых взаимодействий
- Триггер-слова для запуска специальных функций

### Ресурсы
- Добавление, редактирование и удаление ресурсов
- Поиск ресурсов по ключевым словам

### Визитки
- Интерактивное создание визиток с пошаговым диалогом
- Просмотр ранее созданных визиток

### Книги
- Добавление и редактирование книг в базе знаний
- Поиск и фильтрация книг

### Цели
- Управление командными целями с приоритетами и сроками
- Интерактивное добавление целей с помощью ИИ

### Инструкции
- Создание и редактирование инструкций
- Поиск инструкций по авторам и ключевым словам

### Лицензии
- Управление лицензиями с защитой доступа
- Интерактивное добавление лицензий

## Технологии
- Node.js и Express.js для бэкенда
- PostgreSQL (Supabase) для хранения данных
- OpenRouter API для доступа к модели Claude 3.5 Sonnet
- React для фронтенда

## Структура проекта
- `/backend` - серверная часть приложения
  - `/routes` - маршруты API
  - `/db` - работа с базой данных
  - `/services` - вспомогательные сервисы
  - `/docs` - документация
  - `/tests` - тесты
- `/frontend` - клиентская часть приложения

## Установка и запуск

### Требования
- Node.js (версия 16+)
- PostgreSQL (локально или через Supabase)
- API ключ для OpenRouter (для доступа к модели Claude)

### Установка
1. Клонировать репозиторий:
   ```
   git clone https://github.com/yourusername/ATD.PAL.git
   cd ATD.PAL
   ```

2. Установить зависимости:
   ```
   cd backend
   npm install
   ```

3. Создать файл `.env` на основе `env.example`:
   ```
   cp env.example .env
   ```

4. Отредактировать файл `.env`, указав:
   - `DATABASE_URL` - URL для подключения к базе данных PostgreSQL
   - `OPENROUTER_API_KEY` - ключ API для OpenRouter
   - `SUPABASE_URL` и `SUPABASE_SERVICE_KEY` - если используется Supabase

5. Выполнить миграцию базы данных:
   ```
   npm run migrate
   ```

### Запуск
1. Запустить сервер:
   ```
   npm start
   ```
   или в режиме разработки:
   ```
   npm run dev
   ```

2. Сервер будет доступен по адресу: `http://localhost:3000`

### API Endpoints
- `GET /` - Информация о сервере
- `GET /docs` - Документация API
- `GET /health` - Проверка состояния сервера
- `POST /api/chat` - Отправка сообщения в чат
- `GET /api/cards` - Получение списка визиток
- `POST /api/cards` - Создание новой визитки
- `GET /api/resources` - Получение списка ресурсов
- `POST /api/resources` - Добавление нового ресурса
- `GET /api/books` - Получение списка книг
- `POST /api/books` - Добавление новой книги
- `GET /api/goals` - Получение списка целей
- `POST /api/goals` - Добавление новой цели
- `GET /api/guides` - Получение списка инструкций
- `POST /api/guides` - Добавление новой инструкции
- `GET /api/licenses` - Получение списка лицензий
- `POST /api/licenses` - Добавление новой лицензии
